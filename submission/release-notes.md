# Initial release notes

Initial public distribution for LottieFiles Creator.

- Adds three task skills for animation work, LottieFiles GraphQL access, and animation review.
- Adds safe examples for read, pagination, explicit mutation, export, and async jobs.
- Adds installation, privacy, support, release, rollback, and security guidance.
- Pins public Engine contract schema `1.0.0` with SHA-256 `1effca56b6481b2890d0359845e50e99664004e6b3bf2bcb25d1597a589037e7` as release evidence.
- Uses schema placeholders until a public GraphQL schema confirms exact GraphQL field names.

Publication remains blocked until production endpoint and OAuth checks, live host tests, brand and legal approval, and required human and administrator gates are complete.
